Modelos 3D realistas de cada corte, en formato .glb, con el id del corte como nombre:

asado.glb, vacio.glb, bife_angosto.glb, ...

Si un corte tiene modelo acá, la ficha lo muestra en 3D. Si no, muestra la pieza 3D generada por código.
Se pueden generar a partir de una foto (Higgsfield, Meshy, Tripo) o escaneando el corte real con el celular (Polycam, Scaniverse).
Conviene que cada archivo pese menos de 5 MB.
